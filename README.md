# ConcertDate

音乐会日期日历。

## 当前功能

- 按城市筛选
- 城市与剧院联动
- 按剧院筛选
- 按年份筛选
- 选择月份后自动滚动到对应月份
- 按星期几筛选
- 日历可纵向滚动浏览全年
- 有音乐会的日期显示深色事件标记
- 无音乐会的日期显示灰色状态点
- 支持桌面与手机布局

## 数据

杭州大剧院数据由 LocalHub 与公开票务索引合并，并按日期、场馆和标题去重；
已核实但尚未同步到聚合页的新演出会通过短期补充记录保留，过期后自动移除。

当前演示数据位于：

`data/concerts.json`

数据格式：

```json
{
  "date": "2026-09-12",
  "city": "杭州",
  "theater": "杭州大剧院",
  "title": "周末音乐会"
}
```

目前仓库里的音乐会只是用于验证页面交互的示例数据，不代表真实演出安排。

## 本地运行

由于页面通过 `fetch` 读取 JSON，请不要直接双击 `index.html`。可以在仓库目录运行任意静态 HTTP 服务，例如：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

也可以直接部署到 GitHub Pages。
